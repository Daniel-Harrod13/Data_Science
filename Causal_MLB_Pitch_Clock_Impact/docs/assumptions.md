# Assumptions and Threats

## Assumption 1: No Other Major Simultaneous Change Fully Explains the Shift

The design assumes that a major break in game duration after 2023 is primarily attributable to the pitch clock rather than another simultaneous rule, roster, scheduling, or measurement change.

## Assumption 2: Comparable Regular-Season Games

The project compares regular-season MLB games before and after 2023 and adjusts for observable game characteristics.

## Assumption 3: Stable Measurement

Retrosheet's game duration field is assumed to be consistently recorded across seasons.

## Main Threats

- Other 2023 rules, including pickoff limits and larger bases
- Changes in offensive environment
- Pitching strategy changes
- No untreated MLB control group
- Postseason games are excluded by using regular-season game logs only

## How the Project Responds

- Uses multiple seasons before and after the rule change
- Controls for game length, runs, attendance, month, and ballpark
- Visualizes time trends rather than relying only on one regression coefficient
