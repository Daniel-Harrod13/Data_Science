# Variable Dictionary

| Variable | Meaning |
|---|---|
| `date` | Game date |
| `season` | MLB season year |
| `visiting_team` | Away team abbreviation |
| `home_team` | Home team abbreviation |
| `visiting_score` | Away team runs |
| `home_score` | Home team runs |
| `total_runs` | Total runs scored in the game |
| `game_outs` | Official length of game in outs |
| `innings` | Approximate innings, `game_outs / 6` |
| `day_night` | Day or night game indicator from Retrosheet |
| `park_id` | Ballpark identifier |
| `attendance` | Official attendance |
| `duration_minutes` | Official time of game in minutes |
| `visiting_stolen_bases` | Stolen bases by away team |
| `home_stolen_bases` | Stolen bases by home team |
| `total_stolen_bases` | Total stolen bases in the game |
| `post_pitch_clock` | Indicator for 2023+ seasons |
| `month` | Calendar month |
