## Projects

| Project | Description | Technologies |
|---------|-------------|--------------|
| [Phenotypic Association Analysis in HairEyeColor](./Phenotypic_Association_Analysis_in_HairEyeColor/) | Graduate-level R analysis of the built-in `HairEyeColor` dataset using contingency-table inference, effect sizes, and publication-style visualizations, delivered with a final Quarto PDF report. | R, Quarto, ggplot2, dplyr, tidyr |
| [IBM Employee Attrition ML](./IBM_Employee_Attrition_ML/) | Interview-ready end-to-end machine learning case study for attrition risk prediction, including preprocessing pipelines, model selection, subgroup metrics, and deployable artifacts. | Python, pandas, scikit-learn, joblib |
| [IBM Predictive Maintenance ML](./IBM_Predictive_Maintenance_ML/) | Industrial analytics case study that predicts asset failures from telemetry, with time-aware validation, alert thresholding, and deployment-style outputs. | Python, pandas, scikit-learn, joblib |
| [Legacy SAS to Python Module Port](./Legacy_SAS_Python_Module_Port/) | Reimplementation of a legacy SAS-style edit-check and summary routine as a Python module, with pytest parity assertions on synthetic data. | Python, pandas, pytest, SAS (reference), Git |
